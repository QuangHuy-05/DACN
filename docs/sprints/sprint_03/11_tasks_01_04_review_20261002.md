## 3. Sau khi sửa

Submit từng task bị sửa, export **toàn bộ project 6** dưới dạng raw JSON và lưu riêng, ví dụ `data/interim/annotation/sprint03/exports/reannotation_v2/batch_assisted_round2.json`. Pilot chưa có finding chặn trong lượt này; có thể giữ export pilot snapshot nếu project pilot không đổi.

Agent sẽ snapshot export mới vào một review directory mới, chạy lại converter, rồi chạy script 22 vào output directory mới. Không dùng output folder hiện tại làm đích ghi đè. Nếu nội dung đã được phán quyết nhưng vẫn có flag phản ánh sự mơ hồ thật, giữ flag và note có lý do; không xóa flag chỉ để đạt QA.

```bash
cd /mnt/d/DACN
source ~/.venv_labelstudio311/bin/activate

python -m scripts.17_convert_span_annotation_batch \
  --export data/interim/annotation/sprint03/exports/reannotation_v2/batch_assisted_round2.json \
  --queue data/interim/annotation/sprint03/annotation_queue_batch02_train_dev.csv \
  --role train_dev_batch02 \
  --output-dir data/interim/annotation/sprint03/review_next/batch_qa
```

`review_next` là tên ví dụ, phải là thư mục chưa dùng. Script 22 yêu cầu cả snapshot input và QA pilot/batch khớp nhau; xem `--help`. Nếu ca phán quyết vẫn bị rule cảnh báo, ghi quyết định human có nguồn thay vì tự chuyển cả dòng sang approved.

## 5. Runner/scorer đã hiện thực

- `src/data/annotation_release.py` và `scripts/22_review_and_package_train_dev.py`: QA/hash gate, content review, log, split audit, coverage và candidate có cách ly.
- `src/evaluation/dev_runner.py`, `scripts/23_run_span_dev.py`: chỉ đọc `dev_input.jsonl` có `sample_id/text`; truyền mỗi text cho adapter, gắn ID sau inference. Có record cho runtime error, invalid output, abstain; output lỗi được giữ trong raw trace.
- `scripts/24_score_span_dev.py`: đọc gold riêng sau khi prediction đã freeze; kiểm hash corpus/prediction/scorer và viết metrics/error analysis/scoring manifest riêng.
- `schema.py`: thêm status/raw output/error có default để giữ interface cũ.
- `span_scorer.py`: missing prediction tính FN thay vì bỏ mẫu, từ chối ID thừa/lặp, công bố macro all-label/gold-supported/active, T1 null coverage, denominator Quận trên gold moi **không có gold QuanHuyen**, recall Quận trên cu/Lai.

CLI tương lai, chỉ chạy khi corpus đã đạt `TRAIN_DEV_APPROVED_TEST_PENDING` và model ở bước sau đã chuẩn bị:

```bash
python -m scripts.23_run_span_dev \
  --input <APPROVED_CORPUS>/dev_input.jsonl \
  --corpus-manifest <APPROVED_CORPUS>/manifest.json \
  --model-config <FROZEN_MODEL_CONFIG.json> \
  --output-dir <NEW_DEV_RUN_DIR>

python -m scripts.24_score_span_dev \
  --predictions <NEW_DEV_RUN_DIR>/predictions.jsonl \
  --gold <APPROVED_CORPUS>/dev.jsonl \
  --corpus-manifest <APPROVED_CORPUS>/manifest.json \
  --run-dir <NEW_DEV_RUN_DIR>
```

Model config cần `run_id` có dev, `model_id`, seed số nguyên, `supported_labels`, `adapter_factory` dạng `module:Class`, `adapter_kwargs` và `resources`. Mỗi resource dùng path/role/SHA-256; checkpoint, gazetteer, tokenizer, segmenter và rules đều cần được khai báo. Annotation/benchmark không được dùng làm resource model. Ví dụ schema config không thay việc chuẩn bị từng baseline ở bước 5–6.
